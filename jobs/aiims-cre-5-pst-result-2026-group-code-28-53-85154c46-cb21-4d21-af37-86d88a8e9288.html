AIIMS CRE-5 PST Result 2026: Group Code 28 और 53 की सूची जारी

All India Institute of Medical Sciences (AIIMS), New Delhi

विभागAll India Institute of Medical Sciences (AIIMS), New Delhi
परिणाम की तारीख11 November 2026
परिणाम की स्थितिजारी। Group Code 28 Assistant Security Officer और Group Code 53 Fire Technician तथा Security cum Fire Assistant के लिए अलग-अलग PST परिणाम दस्तावेज उपलब्ध हैं।
कट-ऑफ विवरणआधिकारिक परिणाम पेज पर अलग से कटऑफ अंक प्रदर्शित नहीं हैं। संबंधित समूह की PDF में रोल नंबर और पात्रता स्थिति जाँचें।

पूरी जानकारी

सूचना स्रोत और जारी होने की तारीख All India Institute of Medical Sciences, नई दिल्ली के आधिकारिक Results and Announcements पोर्टल पर दोनों परिणाम 11 नवंबर 2026 को प्रकाशित किए गए। AIIMS CRE-5 PST Result 2026 AIIMS ने Common Recruitment Examination CRE-5 के अंतर्गत Group Code 28 और Group Code 53 के उम्मीदवारों के Physical Standards Test परिणाम जारी कर दिए हैं। दोनों समूहों के लिए अलग-अलग परिणाम दस्तावेज उपलब्ध कराए गए हैं। उम्मीदवार को अपने आवेदन में दर्ज समूह कोड के अनुसार सही सूची खोलनी चाहिए। Group Code 28 Assistant Security Officer पद से संबंधित है। Group Code 53 Fire Technician और Security cum Fire Assistant पदों से संबंधित है। रोल नंबर से परिणाम कैसे जाँचें AIIMS के आधिकारिक Results and Announcements पेज पर जाएँ। Latest Results में Group Code 28 या Group Code 53 का PST Result चुनें। अपने समूह कोड से मेल खाने वाली PDF खोलें। PDF में खोज सुविधा का उपयोग करके अपना रोल नंबर दर्ज करें। यदि रोल नंबर सूची में है तो PDF सुरक्षित करें और उसमें दिए गए आगे के निर्देश पढ़ें। परिणाम के बाद क्या करें PST में सफल होना अंतिम नियुक्ति की पुष्टि नहीं है। यह भर्ती प्रक्रिया का एक चरण है। उम्मीदवार अपने परिणाम दस्तावेज में दिए गए निर्देशों और CRE-5 की मूल भर्ती सूचना के अनुसार आगे की प्रक्रिया पूरी करें। अगले चरण की तारीख, स्थान या आवश्यक दस्तावेज के लिए AIIMS द्वारा जारी नई सूचना को ही मान्य मानें। कटऑफ और मेरिट सूची आधिकारिक परिणाम सूची के संक्षिप्त विवरण में अलग से कटऑफ अंक प्रकाशित होने की जानकारी नहीं दी गई है। उम्मीदवारों को संबंधित परिणाम PDF में अपना रोल नंबर और पात्रता स्थिति देखनी चाहिए। किसी अन्य समूह की सूची को अपने समूह का परिणाम न समझें। उम्मीदवारों के लिए जरूरी सावधानी Group Code 28 और 53 के परिणाम अलग-अलग हैं, इसलिए सही PDF चुनना जरूरी है। रोल नंबर के साथ PDF में दिए गए अन्य निर्देश भी पढ़ें। PST पास करने के बाद भी शेष भर्ती औपचारिकताएं पूरी करनी होंगी। अगली सूचना, दस्तावेज सत्यापन या अन्य चरण के लिए केवल AIIMS के आधिकारिक निर्देशों पर भरोसा करें। भर्ती परिणाम और प्रवेश पत्र की सत्यापित जानकारी के लिए SarkariJobAlert पर जाएँ।
