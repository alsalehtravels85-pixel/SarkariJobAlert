DSSSB Draft Answer Key 2026: 21 Post Codes के लिए Objection Schedule जारी

Delhi Subordinate Services Selection Board (DSSSB)

विभागDelhi Subordinate Services Selection Board (DSSSB)
परिणाम की तारीख04 November 2026
परिणाम की स्थितिDraft Answer Key objection schedule जारी; 21 Post Codes शामिल। 15.11.2026 के बाद आने वाली windows: 21/26,26/26,23/26,16/26 (16–20 Nov); 34/26 (22–26 Nov); 27/26 (24–28 Nov); 28/26,30/26,29/26,22/26,25/26,24/26 (28 Nov–02 Dec); 41/26,71/25,72/25 (08–12 Dec).

पूरी जानकारी

DSSSB ने 4 नवंबर 2026 को विभिन्न computer-based examinations की Draft Answer Keys देखने और objections दर्ज करने के लिए 21 Post Codes का अलग-अलग समय-सारणी वाला notice जारी किया है। यह कोई नई vacancy या नया examination form नहीं है। जिन उम्मीदवारों ने संबंधित post code की परीक्षा दी थी, वे अपने admit card पर दर्ज code के अनुसार objection window पहचानें और केवल उसी अवधि में response sheet तथा draft answer key की जांच करें। कौन-से Post Codes की window अभी आगे है? 15 नवंबर 2026 की स्थिति में निम्नलिखित windows आने वाली हैं: • 21/26, 26/26, 23/26 और 16/26: 16 नवंबर से 20 नवंबर 2026। • 34/26: 22 नवंबर से 26 नवंबर 2026। • 27/26: 24 नवंबर से 28 नवंबर 2026। • 28/26, 30/26, 29/26, 22/26, 25/26 और 24/26: 28 नवंबर से 2 दिसंबर 2026। • 41/26, 71/25 और 72/25: 8 दिसंबर से 12 दिसंबर 2026। इस notice में post names नहीं दिए गए हैं; इसमें केवल post codes और objection dates प्रकाशित हैं। इसलिए उम्मीदवार अपने admit card, परीक्षा सूचना या आवेदन विवरण में दर्ज code से मिलान किए बिना किसी दूसरे code की answer key न खोलें। कौन-सी शुरुआती windows बंद हो चुकी हैं? 40/26, 15/26, 39/26 और 19/26 के लिए objection अवधि 6 से 10 नवंबर थी। 42/26 और 31/26 के लिए अवधि 10 से 14 नवंबर थी। ये समय सीमाएं 15 नवंबर तक समाप्त हो चुकी हैं। यदि आपका code इन्हीं में है, तो सामान्य objection window अब बंद है; बाद में objection भेजने की सुविधा इस notice में नहीं दी गई है। Answer Key और Response Sheet कैसे देखें? उम्मीदवार DSSSB की official website पर जाकर “Objection Link for Various Post Codes” विकल्प खोलें। अपने post code के सामने दी गई तारीखों में login करके draft answer key और response sheet देखें। प्रश्न संख्या, चुना गया उत्तर और बोर्ड की प्रस्तावित answer key का मिलान सावधानी से करें। यदि किसी प्रश्न या उत्तर में आपत्ति है, तो निर्धारित online objection प्रक्रिया और help file के अनुसार supporting explanation/document दें। Objection जमा करने से पहले हर प्रश्न का सही reference, उपलब्ध प्रमाण और portal पर दिख रही अंतिम submission status सुरक्षित रखें। अंतिम दिन तक इंतजार करने से login या payment/portal संबंधी तकनीकी समस्या का जोखिम बढ़ सकता है। Objection window बंद होने के बाद इस notice में किसी सामान्य extension का प्रावधान नहीं बताया गया है। महत्वपूर्ण सावधानियां यह consolidated schedule अलग-अलग post codes के लिए है, इसलिए सभी उम्मीदवारों की अंतिम तारीख एक जैसी नहीं है। अपने code की start और end date अलग से नोट करें। किसी दूसरे post code की तारीख को अपनी परीक्षा पर लागू न करें। Notice में answer key objection के लिए अलग शुल्क का उल्लेख नहीं है; portal पर यदि कोई अतिरिक्त instruction दिखे तो उसे पढ़कर ही आगे बढ़ें। इस सूचना का उद्देश्य उम्मीदवारों को उनके code के अनुसार सही objection अवधि पहचानने में मदद करना है। Answer key पर आपत्ति दर्ज करना अंतिम result या selection की गारंटी नहीं है। अधिक सत्यापित परीक्षा, परिणाम और भर्ती अपडेट के लिए SarkariJobAlert वेबसाइट देखें।
