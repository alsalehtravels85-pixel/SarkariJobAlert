C. In GitHub repository Settings > Secrets and variables > Actions, ensure secrets exist:
   - SUPABASE_URL
   - SUPABASE_SERVICE_ROLE_KEY
   Never put the service-role key in config.js or in public HTML/JS.
D. Open GitHub Actions > Daily School Exam Guide Publishing > Run workflow. Confirm the run succeeds.
E. Open education.html on the deployed website. It will show articles only after the SQL has run and workflow has successfully inserted one.
F. Test Admin Panel login, create/update/publish/unpublish/delete using a test record. Do not test Delete on a real important post.
